# 민원 데이터가 쌓이지 않는 문제 해결

## 원인

민원 결과 화면에서 기록을 저장할 때 데이터베이스에 `usage_logs`라는 표가 있고 "누구나 기록할 수 있다"는 규칙도 있지만, 실제로 표에 **쓸 수 있는 권한 부여가 빠져 있었습니다.** 그래서 앱에서 저장을 시도해도 데이터베이스가 조용히 거절해 표가 계속 비어 있습니다(현재 0건 확인).

같은 이유로 관리자 페이지의 조회 권한도 빠져 있어, 앞으로 기록이 쌓여도 제대로 보이지 않을 수 있습니다.

## 변경 사항

데이터베이스 권한을 추가하는 한 번의 변경만 적용합니다 (앱 코드 변경 없음):

- 일반 사용자(앱 이용자): `usage_logs` 표에 **기록 추가** 권한 부여
- 관리자 조회(서버 전용): `usage_logs` 표에 **모든 권한** 부여
- 기존 보안 규칙은 그대로 유지 — 일반 사용자는 기록을 추가만 할 수 있고, 내용을 보거나 수정·삭제할 수는 없음

## 확인 방법

변경 후 앱에서 민원 상담을 한 번 끝까지 진행한 뒤 관리자 페이지를 새로고침하면 기록 1건과 통계가 나타나는 것으로 확인합니다.
